# Stride

Plant protein bar landing page with a 3D bar (Three.js). Single file: `index.html`.

## Live on GitHub Pages
1. Repo ke root me `index.html`, `.nojekyll` aur `README.md` upload karo.
2. Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
3. 1-2 minute baad site `https://<username>.github.io/<repo>/` par live hogi.

Internet chahiye: Three.js (jsDelivr), fonts (Google Fonts), intro video aur ingredient sheet (Higgsfield links).
